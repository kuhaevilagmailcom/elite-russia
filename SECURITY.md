# Security
Sandbox only. Live operations fail closed. Session tokens hashed, Telegram initData validated, replay guarded, quote bound to user/price/version, money stored as integer, journal immutable, integrity checker prevents mutations after detected mismatch. API does not have fine-grained role tiers, independent audit, signing or external payment verification. Never send real funds or gifts. SQLite integrity and local HTTP tests are not production certification. No private keys, tokens or sessions in Git. Report defects privately to project owner.

Beta 2: do not run legacy runtime against an upgraded Ledger V2 database. Async runtime has persistent ledger pause on detected projection mismatch. PostgreSQL advisory lock is a conservative serialization strategy, not proof of production scalability. TON proof uses Ed25519 and SDK fixed-wallet checks; actual SDK/live integration not verified. No mainnet, custody credit or transfer allowed. Never expose secrets in API responses or commit .env. External financial launch requires independent audit and platform/legal review.
