# База данных
SQLite — действующая sandbox БД. `migrations/001_market.sql` — проект схемы PostgreSQL. Для изолированного sandbox: выполнить `node --experimental-sqlite scripts/migrate-sqlite-to-postgres.mjs data/minion.sqlite demo-import.sql --demo-sandbox`, затем в новой пустой тестовой БД `psql -v ON_ERROR_STOP=1 -f migrations/001_market.sql` и `psql -v ON_ERROR_STOP=1 -f demo-import.sql`. Экспорт создаёт backup, проверяет integrity/foreign keys и вставляет проверки количества и Ledger. Не импортировать demo в production. PostgreSQL runtime не реализован; CI предназначен для проверки схемы.
