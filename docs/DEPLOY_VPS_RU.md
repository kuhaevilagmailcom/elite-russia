# Развёртывание sandbox
На сервере с Docker: `docker compose up --build -d`. Доступ только через localhost; для просмотра использовать защищённый SSH tunnel или локальный браузер. Контейнер сохраняет SQLite в volume. Production не поддерживается. Для настоящего Mini App нужны HTTPS домен и отдельно настроенный restricted сервер; не публиковать demo как финансовую площадку. Настроить TLS reverse proxy, секреты, бэкапы и мониторинг перед подключением реального Telegram. Не включать финансовые flags.
