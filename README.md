# ПЕРЕКУП v4 — симулятор перекупа

Это не кликер: игрок ищет объявление, проверяет машину, покупает, диагностирует, чинит, делает детейлинг/покраску и продаёт системным дилерам через быстрый выкуп или торги.

## Что изменено

- полностью новый мобильный интерфейс 320–430 px;
- шрифт Manrope: заголовки 700–800, вторичный текст 400–500;
- иконки Lucide + больше аккуратных emoji;
- стартовый баланс 100 000 ₽;
- поиск машины 1 000 ₽;
- прогресс классов: АвтоВАЗ → Иномарки → Бизнес → Премиум → Топ-класс;
- на старте только бюджетные LADA, никаких суперкаров;
- диагностика скрытых дефектов;
- ремонт тормозов/подвески/кузова/двигателя/коробки и т.д.;
- детейлинг и покраска повышают стоимость;
- быстрый системный выкуп;
- 30-секундные торги между системными дилерами;
- игроки друг у друга машины не покупают;
- задания основаны на реальных игровых действиях;
- рейтинг, бонус дня, классы, достижения, профиль, статистика, правила;
- админ-панель: баланс, уровень, репутация, блокировка, выдача машины, полный сброс игрока.

## Запуск Windows PowerShell

Распакуй ZIP в новую папку и выполни:

```powershell
cd "C:\Users\1\Downloads\perekup-game-v4"
npm.cmd start
```

Открыть:

```text
http://localhost:8080
```

Локальный dev-пользователь `10001` автоматически является админом.

## Telegram

Для production укажи в `.env`/переменных окружения `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL`, `ADMIN_IDS` и отключи dev-auth через `ALLOW_DEV_AUTH=0`.

Реальные прозрачные PNG автомобилей загружаются из публичных GitHub assets. Если картинка недоступна, интерфейс показывает аккуратный fallback 🚘, а не квадратную заглушку.
