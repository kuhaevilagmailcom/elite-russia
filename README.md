# DEZ REMKA Telegram Bot

Готовая сборка для Bothost.

## Запуск

Главный файл: `bot.py`

Сторонние Python-библиотеки не требуются.

## Переменные окружения

Обязательная:

- `BOT_TOKEN` — токен Telegram-бота.

Дополнительные:

- `ADMIN_CHAT_ID` — Telegram ID администратора для заявок и админ-панели.
- `PAYMENT_PROVIDER_TOKEN` — токен платежного провайдера Telegram Payments.
- `DATA_DIR` — путь к данным. На Bothost можно не задавать: при наличии `/app/data` бот использует его автоматически.

Не добавляйте реальные токены в GitHub.

## Bothost

Укажите репозиторий, ветку `main` и главный файл `bot.py`.
SQLite создается автоматически при первом запуске.
