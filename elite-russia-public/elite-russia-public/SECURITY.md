# Security Policy

This repository contains only public examples and documentation.

Please do not report leaked secrets through public issues. If you notice sensitive data, contact the maintainers privately and include:

- affected file path;
- commit hash, if available;
- short explanation of the issue.

## Never commit

- `.env` files;
- API keys;
- Telegram bot tokens;
- database passwords;
- production manifests with private URLs;
- paid or third-party game assets;
- full client archives.
