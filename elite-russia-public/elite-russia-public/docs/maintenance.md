# Maintenance

The public repository is maintained as a clean reference for the project.

## Regular tasks

- review interface contract changes;
- keep examples working in a browser;
- update launcher manifest examples when the update flow changes;
- close outdated issues;
- document breaking changes in `CHANGELOG.md`;
- create releases for public snapshots.

## Triage labels

Suggested labels:

- `interface`
- `launcher`
- `docs`
- `bug`
- `enhancement`
- `good first issue`
- `security`
